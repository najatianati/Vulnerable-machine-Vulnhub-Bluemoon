# Bluemoon (2021) – System Hacking Walkthrough

## 1. Project Overview

This project documents the Week 3 System Hacking practical using the Bluemoon (2021) vulnerable virtual machine.

The practical was conducted using Kali Linux as the attacker machine and Bluemoon (2021) as the target machine, with Oracle VirtualBox as the virtualization platform.

The main purpose of this practical was to investigate the security weaknesses of the target machine by performing reconnaissance, information gathering, gaining initial access and privilege escalation.

Throughout this exercise, several security weaknesses were identified, including weak FTP credentials, an insecure feedback script and an insecure Docker configuration. The practical was completed by successfully retrieving the User-2 Flag and Root Flag from the target machine.

## 2. Objectives

The objectives of this practical are:

- To identify open ports and services running on the Bluemoon target machine.
- To discover hidden directories and gather useful information from the target machine.
- To obtain initial access through the available services.
- To investigate privilege escalation techniques and identify security misconfigurations.
- To examine Docker container configurations and their security risks.
- To retrieve the User-2 Flag and Root Flag.
- To understand the security weaknesses discovered and recommend appropriate countermeasures.
